# ពណ៌គោលរបស់ VVC Website

ឯកសារនេះសង្ខេបតែពណ៌សំខាន់ៗ ដែលប្រើជាមូលដ្ឋានក្នុង VVC website ប៉ុណ្ណោះ។ ពណ៌ទាំងនេះត្រូវបានកំណត់នៅក្នុង `src/index.css`។

## ពណ៌សំខាន់ៗ

| Token | ពណ៌ | ការប្រើប្រាស់សំខាន់ |
| --- | --- | --- |
| `--fog` | `#fffaf0` | ផ្ទៃខាងក្រោយសំខាន់របស់ website |
| `--white` | `#ffffff` | ផ្ទៃ card, panel និងផ្ទៃស្អាតៗ |
| `--ink` | `#111827` | អក្សរសំខាន់សម្រាប់ body text |
| `--coal` | `#0f172a` | ចំណងជើង និងអក្សរដែលត្រូវការបញ្ជាក់ខ្លាំង |
| `--gold` | `#c79a2d` | ពណ៌ brand សំខាន់ សម្រាប់ button និង active state |
| `--gold-deep` | `#9f761f` | ពណ៌មាសងងឹត សម្រាប់ link, label និង hover |
| `--gold-soft` | `#fff7df` | ផ្ទៃមាសស្រាល សម្រាប់ badge ឬ highlight background |

## ការប្រើប្រាស់ណែនាំ

- ប្រើ `--fog` ជា background សំខាន់របស់ទំព័រ។
- ប្រើ `--white` សម្រាប់ card និង panel។
- ប្រើ `--ink` សម្រាប់អត្ថបទធម្មតា។
- ប្រើ `--coal` សម្រាប់ heading ឬអត្ថបទដែលចង់ឱ្យច្បាស់ខ្លាំង។
- ប្រើ `--gold` សម្រាប់ primary button និងចំណុច brand សំខាន់។
- ប្រើ `--gold-deep` សម្រាប់ hover, link និង label។
- ប្រើ `--gold-soft` សម្រាប់ផ្ទៃ highlight ស្រាលៗ។
